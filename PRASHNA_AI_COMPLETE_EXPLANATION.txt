1. PROJECT OVERVIEW
================================================================================

Prashna AI is a specialized AI-powered study assistant designed exclusively for 
competitive exam preparation. Version 3.0.0 focuses on helping Indian students 
prepare for major competitive exams including:

• JEE (Joint Entrance Examination) - Engineering
• NEET (National Eligibility cum Entrance Test) - Medical
• UPSC (Union Public Service Commission) - Civil Services
• GATE (Graduate Aptitude Test in Engineering) - Postgraduate

The bot enforces strict academic focus and provides structured, accurate answers 
to study-related questions while refusing off-topic conversations.

2. CORE ARCHITECTURE
================================================================================

BACKEND TECHNOLOGY STACK:
───────────────────────────────────────────────────────────────────────────────
• Framework: FastAPI (Python) - Modern, fast web framework
• AI Model: Baidu ERNIE-4.5-VL-28B-A3B-PT via HuggingFace Hub
• Web Search: DuckDuckGo Search integration for current information
• Deployment: Vercel serverless functions for production
• Local Dev: Uvicorn ASGI server for development

FRONTEND TECHNOLOGY:
───────────────────────────────────────────────────────────────────────────────
• UI Framework: Vanilla JavaScript with modern CSS
• Math Rendering: KaTeX library for mathematical equations
• Theme System: Light/Dark mode with CSS custom properties
• Responsive Design: Mobile-first approach with CSS Grid/Flexbox
• Real-time Updates: Server-Sent Events (SSE) for streaming

DATA FLOW ARCHITECTURE:
───────────────────────────────────────────────────────────────────────────────
1. User Input (Text/Image) → Frontend Validation
2. Frontend → API Endpoint (/api/chat/stream)
3. Backend Processing:
   • Topic restriction enforcement
   • Web search (if triggered)
   • AI model query via HuggingFace
4. Streaming Response → Frontend Real-time Display
5. Conversation Storage → Local Browser Storage

5. API ENDPOINTS
================================================================================

5.1 /api/chat/stream (POST)
───────────────────────────────────────────────────────────────────────────────
PURPOSE: Main chat completion endpoint
REQUEST BODY:
{
  "messages": [
    {
      "role": "user|assistant|system",
      "content": "string|MessageContent[]"
    }
  ],
  "max_tokens": 512,
  "temperature": 0.3,
  "system_prompt": "string",
  "web_search": false
}

RESPONSE FORMAT: Server-Sent Events (SSE)
• data: {"searching": true, "query": "..."}     - Web search started
• data: {"sources": [{"title": "...", "url": "..."}]} - Search results
• data: {"token": "...", "done": false}        - Streaming tokens
• data: {"token": "", "done": true}             - Response complete
• data: {"error": "...", "done": true}          - Error occurred

5.2 /api/health (GET)
───────────────────────────────────────────────────────────────────────────────
PURPOSE: Health check endpoint
RESPONSE:
{
  "status": "ok",
  "model": "baidu/ERNIE-4.5-VL-28B-A3B-PT"
}

5.3 / (GET) - Local Development Only
───────────────────────────────────────────────────────────────────────────────
PURPOSE: Serves the main frontend application
RESPONSE: HTML page with full frontend
